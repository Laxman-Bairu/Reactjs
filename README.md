This is a simple React application demonstrating:

- React setup with **create-react-app**
- Using **Bootstrap 5** for styling
- Routing with **React Router v6**
- Form handling with React hooks
- JSON Server as a fake backend API
- Organized API calls via a service layer

📦 Installation

git clone : https://github.com/Laxman-Bairu/Reactjs.git

cd your-repo

npm install

npm start
